# Проект: Мессенджер + PWA

## Цель
- Свой мессенджер-сервер (аккаунты, сообщения, хранение)
- PWA-клиент с красивым дизайном

## Требования (MVP)
- Авторизация: телефон + код
- Кабинет/профиль: история чатов
- Поиск контактов (по id)
- В чате: загрузка фото до 5MB

## Инфраструктура
- Домен: notificbot.ru
- TLS: Let's Encrypt

## Архитектура (черновик)
- Backend API (например: Node/NestJS или Go) + WebSocket для realtime
- DB: Postgres
- Хранилище медиа: локальный volume или S3-совместимое (MinIO) + выдача через подписанные URL
- Reverse proxy: Caddy/Traefik/Nginx с автополучением сертификатов

## Авторизация по телефону
Варианты доставки кода:
- SMS провайдер (платно)
- Telegram/WhatsApp бот как канал доставки (не SMS)
- «Звонок с кодом» (провайдер)
- На старте можно dev-режим: код в логах/в админке, потом заменить провайдер
